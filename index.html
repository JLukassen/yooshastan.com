Tinymix Utility — APatch Adaptation

An experimental adaptation of an existing Magisk Tinymix installer for the APatch root framework. Explored low-level Android audio mixer access, module packaging, filesystem permissions and boot scripts on a Pixel 8a running Android 15.

Tinymix and the Tinymix Manager GUI are third-party projects. This adaptation is shown as an earlier technical experiment and is not offered here as a maintained download.
